# Kitapstudio – sürümler

Arapça metin, şerh, haşiye ve dipnotlu kitap editörü **Kitapstudio**'nun kurulum dosyaları.

- **Windows:** `Kitapstudio-Kurulum-<sürüm>.exe` — bir kez kurun; sonraki sürümler uygulamanın içinden "Şimdi güncelle" ile gelir.
- **Android:** `Kitapstudio-Android-<sürüm>.apk`
- **Mac:** `Kitapstudio-<sürüm>-arm64.dmg` (Apple M işlemci) veya `-x64.dmg` (Intel)

Son sürüm: [Releases](../../releases/latest)
